### 🔁 phhbr.de is now bruchner.dev

This site started in 2020 as a small Jekyll blog under my handle. Since September 2025 I've been working as a freelance software engineer, and the old site didn't reflect that anymore: a chronological blog, three different contact addresses, and a freelance pitch buried in a post.

So I rebuilt it. Same person, new name on the door.

***

### 🧭 What changed

- **New domain:** everything now lives at **bruchner.dev**. Old links to phhbr.de redirect permanently, so nothing you bookmarked breaks.
- **Portfolio first:** the start page and [services](/services/) now say what I do and how to work with me. My [CV](/cv/) is a proper page instead of a list.
- **One contact address** instead of three.
- **The old posts stay:** they're [archived](/writing/) at their original URLs, with a note where things have changed since.

***

### 🛠️ Under the hood

Since this is a developer's site, it should practise what it preaches:

- **Astro** instead of Jekyll, generating plain static HTML
- **Self-hosted on my own server in Germany** instead of GitHub Pages
- **No cookies, no analytics, no third-party requests.** Fonts are served from this server too, so your visit isn't reported to anyone
- **A strict Content Security Policy** and a build step that fails if any inline script or style sneaks in
- **Accessibility as a requirement:** keyboard navigation, visible focus, sufficient contrast in light and dark mode
